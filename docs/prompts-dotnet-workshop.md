# Prompts Dotnet Workshop

## Prompt 1
```text
Concois une application console .NET, genere la structure du projet, le code de depart, les commandes de build et la documentation Markdown.
```

## Prompt 2
```text
Concois une Web API .NET avec un projet de tests xUnit, documente les commandes dotnet et ajoute un diagramme Mermaid des dependances.
```

