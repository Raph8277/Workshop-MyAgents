# Prompts SQLite Workshop

## Prompt 1
```text
Concois une base SQLite pour une application de gestion de stock, genere le schema SQL, explique la creation du fichier .db, documente les tables en Markdown et ajoute un diagramme Mermaid ER.
```

## Prompt 2
```text
Modele une base SQLite pour un blog avec auteurs, articles et tags, puis produis le script SQL, la documentation .md et le schema Mermaid correspondant.
```

## Prompt 3
```text
Propose une architecture SQLite pour une application hors ligne de prise de notes, avec contraintes, indexes, exemples de build et documentation pedagogique.
```

## Prompt 4
```text
Concois une base SQLite de gestion de bibliotheque, genere le schema SQL, ajoute un seed de donnees, prepare une migration evolutive, documente le tout en Markdown et produis un diagramme Mermaid ER.
```
