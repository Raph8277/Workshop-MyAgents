# Prompts Git Workshop

## Prompt 1
```text
Concois une strategie Git pour creer une branche locale depuis main, la publier sur origin et preparer une pull request en mode merge. Donne les commandes et un schema Mermaid.
```

## Prompt 2
```text
Concois une strategie Git pour creer une branche locale depuis dev, la publier sur origin et preparer une pull request en mode rebase. Donne les commandes, les risques et un schema Mermaid.
```

## Prompt 3
```text
Explique quand choisir merge ou rebase pour une branche feature deja partagee avec l'equipe, puis documente le workflow recommande.
```
